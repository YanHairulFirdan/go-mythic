# Sparta Ledger — What's New

## Release overview

Sparta Ledger now provides a clearer financial overview, faster daily data entry, stronger account recovery, and company-wide branding controls. The latest improvements focus on reducing manual work while keeping Owner and Employee access separated.

## 1. More useful Dashboard

### Dynamic performance summary

The Dashboard now uses actual company transactions to show:

- Total income
- Total expenses
- Net performance
- A period-based performance summary
- A contextual greeting for the logged-in user

The figures are calculated from saved data instead of placeholder values.

### Recent transactions

A new **Transaksi terbaru** section shows the latest company transactions directly on the Dashboard. Users can review recent activity without opening the full transaction list.

### Invoice reminders

The invoice notice is now dynamic. It reflects the company’s current invoice data, including:

- Unpaid invoices
- Partially used invoices
- A reminder to review invoices before their due date

The notice updates as invoice and transaction data changes.

## 2. Faster transaction entry

### Quick-create customer and category

Users can create a customer or transaction category directly from the transaction form when the required option does not exist yet.

Benefits:

- No need to leave the transaction form
- Less interruption during data entry
- New customers and categories are available immediately after creation
- The same experience is available when creating or editing a transaction

## 3. Improved capital management

### Edit and delete capital records

Owners can now correct or remove capital entries from the capital management screen.

### Flexible capital duration

Capital entries can now be:

- Open-ended, when no end date is known
- Set with a specific end date
- Managed using a one-year duration when applicable

This supports real-world capital arrangements that do not always have a fixed closing date.

## 4. Better money input experience

Currency fields now format numbers with thousand separators while users type. This makes large amounts easier to read and reduces input mistakes across key financial forms, including:

- Transactions
- Invoices
- Capital entries
- Customer and employee-related financial views
- Reports

The stored values remain numeric and ready for calculation.

## 5. Account and password improvements

### Password reset from Profile

A logged-in user who forgets their password can request a reset link from **Profile** without entering their old password.

The reset link is sent only to the email address currently associated with that account. The existing change-password flow remains available for users who know their current password.

### Cleaner account menu

The account dropdown now uses the authenticated user’s information consistently throughout the application.

## 6. Dedicated company appearance settings

### Branding moved out of Profile

Company branding is now managed from a dedicated **Tampilan aplikasi** page under **Lainnya / More**. Profile is now focused on account information, password security, and account deletion.

### Available branding controls

Owners can:

- Choose a primary color preset
- Enter a custom six-digit hex color
- Preview the selected color
- Upload a company logo
- Remove the saved logo
- Apply the branding across the application

Branding settings are Owner-only. Employees do not see the menu item, and direct access is blocked.

## 7. Cleaner navigation

The navigation has been refined to keep commonly used account and business actions easier to find:

- Profile remains dedicated to personal account and security settings
- Appearance settings are grouped under More
- Owner-only business management pages remain restricted to Owners
- The inactive notification bell has been removed

## Role-based access

| Area | Owner | Employee |
|---|---:|---:|
| Dashboard and permitted financial activity | Yes | Yes, based on permission scope |
| Company appearance settings | Yes | No |
| Employee management | Yes | No |
| Capital management | Yes | Based on configured access |
| Profile and password recovery | Yes | Yes |

## Suggested client demonstration flow

1. Open the Dashboard and point out the dynamic performance summary.
2. Show the recent transactions list.
3. Show the invoice reminder changing with invoice status.
4. Open a transaction form and demonstrate quick-create customer/category.
5. Open Capital and demonstrate editing an existing entry.
6. Create or edit an open-ended capital entry without an end date.
7. Open Profile and show the password reset action.
8. Open **Lainnya / More → Tampilan aplikasi** as an Owner.
9. Change the color, preview it, upload a logo, and save.
10. Navigate to another page to show that the branding is applied globally.

## Client value summary

- Faster daily bookkeeping
- Fewer interruptions during transaction entry
- Better visibility into current financial activity
- More reliable invoice follow-up
- Flexible capital tracking
- Easier password recovery
- Stronger separation between account settings and company settings
- More consistent company branding
- Clearer Owner and Employee access boundaries
